# WKD-Bangla-EdTech-App: Master Plan (প্রজেক্টের রূপরেখা)

## 🎯 আমাদের লক্ষ্য (Vision)
বাংলাদেশের শিক্ষার্থীদের মুখস্থবিদ্যার বাইরে এনে গবেষণা-ভিত্তিক, ভিজ্যুয়াল এবং আন্তর্জাতিক মানের শিক্ষা নিশ্চিত করা। বিজ্ঞান ও গণিতকে ভয়ের বিষয় না করে বাস্তব জীবনের সাথে যুক্ত করে শেখানো।

## 🚀 প্রাথমিক ফিচারসমূহ (MVP - Minimum Viable Product)
আমরা প্রথমে ৯ম-১০ম শ্রেণির গণিত ও বিজ্ঞান বিষয়ের উপর ফোকাস করব। প্রথম সংস্করণে যা যা থাকবে:

- **🎬 ভিজুয়াল লার্নিং (সূত্রের বাস্তব ব্যবহার):** Mark Rober স্টাইলে মজার এবং বাস্তব উদাহরণের মাধ্যমে সূত্র শেখানো।
- **🤖 AI ম্যাথ সলভার (বাংলা):** শিক্ষার্থীদের অংকের ছবি তুললে বা লিখলে AI ধাপে ধাপে বাংলায় সমাধান বুঝিয়ে দেবে।
- **📝 সাপ্তাহিক পরীক্ষা:** অ্যাপের ভেতরেই ছোট ছোট কুইজ ও MCQ পরীক্ষা।
- **👨‍👩‍👧 অভিভাবক রিপোর্ট:** শিক্ষার্থীর ফলাফল ও অগ্রগতি সরাসরি অভিভাবকের মোবাইলে SMS বা নোটিফিকেশনের মাধ্যমে পাঠানো।

## 🛠️ প্রযুক্তি (Technology)
- **App:** Flutter (Android & iOS)
- **Backend & Database:** Firebase
- **AI Engine:** OpenAI API / Claude API (বাংলা প্রম্পট সহ)
- **Version Control:** GitHub
